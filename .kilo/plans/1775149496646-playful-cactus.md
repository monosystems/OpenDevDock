# Slice 6: Session Historie - Implementierungsplan

## Überblick

Slice 6 implementiert die **Session Historie** - die Fähigkeit, vergangene Arbeitsstände wiederzufinden und wiederherzustellen. Das ist die Grundlage für einen arbeitsplatzähnlichen Workflow.

## Voraussetzungen

Slice 5 (Session-Änderungskern) ist bereits **teilweise** in der Codebasis vorhanden:
- ✅ `Session` Typ definiert (`src/state/types.ts:50-57`)
- ✅ `createSession()` erstellt Sessions mit Auto-Name (`src/hooks/useSession.ts:10-21`)
- ✅ `trackFileChange()` erfasst Änderungen (`src/hooks/useSession.ts:27-65`)
- ✅ `ChangesTab` zeigt Diffs an (`src/components/ChangesTab.tsx`)

**Fehlende Slice 5 Features** (müssen zuerst implementiert werden):
- ❌ Aktive Session im zentralen State (z.B. React Context)
- ❌ Persistenz der Session-Historie (bleibt nach App-Neustart erhalten)

### 1.4 Session-Name aktualisieren

```typescript
const updateSessionName = useCallback((sessionId: string, newName: string) => {
  setActiveSession(prev => {
    if (!prev || prev.id !== sessionId) return prev;
    return { ...prev, name: newName };
  });
  setSessionHistory(prev => prev.map(s => 
    s.id === sessionId ? { ...s, name: newName } : s
  ));
}, []);
```

## Task 1: Session-Historie State und Persistenz (PRO PROJEKT)

**Datei:** `src/hooks/useSession.ts`

```typescript
const MAX_SESSIONS = 10;

const [sessionsByProject, setSessionsByProject] = useState<Record<string, Session[]>>({});

const closeSession = useCallback(() => {
  if (activeSession) {
    const projectSessions = sessionsByProject[activeSession.projectPath] || [];
    const newProjectSessions = [activeSession, ...projectSessions].slice(0, MAX_SESSIONS);
    
    setSessionsByProject(prev => ({
      ...prev,
      [activeSession.projectPath]: newProjectSessions,
    }));
    
    localStorage.setItem(
      `opendevdock_sessions_${activeSession.projectPath}`,
      JSON.stringify(newProjectSessions)
    );
  }
  setActiveSession(null);
}, [activeSession, sessionsByProject]);
```

## Task 2: Git-Integration in Rust

**Datei:** `src-tauri/src/lib.rs`

```rust
#[tauri::command]
fn get_git_branch(path: String) -> Result<String, String> {
    let output = std::process::Command::new("git")
        .args(["-C", &path, "rev-parse", "--abbrev-ref", "HEAD"])
        .output()
        .map_err(|e| e.to_string())?;
    
    if output.status.success() {
        Ok(String::from_utf8_lossy(&output.stdout).trim().to_string())
    } else {
        Err("Not a git repository".to_string())
    }
}

#[tauri::command]
fn is_git_repository(path: String) -> bool {
    std::path::Path::new(&path).join(".git").exists()
}
```

**Datei:** `src/commands/fileOperations.ts`

```typescript
export async function getGitBranch(path: string): Promise<string | null> {
  try {
    return await invoke<string>("get_git_branch", { path });
  } catch {
    return null;
  }
}

export async function isGitRepository(path: string): Promise<boolean> {
  try {
    return await invoke<boolean>("is_git_repository", { path });
  } catch {
    return false;
  }
```
