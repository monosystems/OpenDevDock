# Slice 5 - Session Änderungskern: Implementierungsplan

## Übersicht

Slice 5 implementiert die Session-basierte Änderungsverfolgung. Jedes geöffnete Projekt erzeugt eine Session, die alle Änderungen (erstellt, bearbeitet, gelöscht) mitverfolgt und in einer Diff-Ansicht darstellt.

## Aufgaben

- [x] Beim Öffnen eines Projekts automatisch eine neue Session anlegen
- [x] Aktive Session sauber im zentralen State führen
- [x] Änderungen der aktuellen Session erfassen
- [x] Geänderte Dateien der aktuellen Session im File Tree markieren
- [x] Einen eigenen Diff- oder Änderungstab für die aktuelle Session anlegen
- [x] Die Änderungsansicht als read-only umsetzen
- [x] Alt- und Neu-Vergleich für geänderte Inhalte darstellen
- [x] Sicherstellen, dass die Session-Änderungslogik im Alltag verständlich und verlässlich funktioniert

## 4. Session Management Hook (`src/hooks/useSession.ts`)

**Neuer Hook:**

```typescript
import { useState, useCallback, useRef } from "react";
import { Session, ChangedFile, ChangeType, Project } from "../state/types";
import { readFileContent } from "../commands/fileOperations";

export function useSession() {
  const [activeSession, setActiveSession] = useState<Session | null>(null);
  const sessionRef = useRef<Session | null>(null);
  sessionRef.current = activeSession;

  const createSession = useCallback((project: Project): Session => {
    const session: Session = {
      id: `session-${Date.now()}`,
      projectPath: project.path,
      projectName: project.name,
      createdAt: Date.now(),
      name: `${project.name} - ${new Date().toLocaleString()}`,
      changedFiles: [],
    };
    setActiveSession(session);
    return session;
  }, []);

  const trackFileChange = useCallback(async (
    path: string,
    name: string,
    changeType: ChangeType,
    originalContent: string | null = null
  ) => {
    const session = sessionRef.current;
    if (!session) return;

    let currentContent: string | null = null;
    if (changeType !== "deleted") {
      try {
        currentContent = await readFileContent(path);
      } catch (e) {
        console.error("Failed to read current content:", e);
      }
    }

    const changedFile: ChangedFile = {
      path,
      name,
      changeType,
      originalContent,
      currentContent,
      timestamp: Date.now(),
    };

    setActiveSession((prev) => {
      if (!prev) return prev;
      // Bestehende Änderung für diese Datei ersetzen oder neue hinzufügen
      const existingIndex = prev.changedFiles.findIndex(f => f.path === path);
      const newChangedFiles = [...prev.changedFiles];
      if (existingIndex >= 0) {
        newChangedFiles[existingIndex] = changedFile;
      } else {
        newChangedFiles.push(changedFile);
      }
      return { ...prev, changedFiles: newChangedFiles };
    });
  }, []);

  const clearSession = useCallback(() => {
    setActiveSession(null);
  }, []);

  return {
    activeSession,
    createSession,
    trackFileChange,
    clearSession,
  };
}
```

## Zu beachtende Punkte

- **Race Conditions**: `readFileContent` ist async - bei schnellen Operationen kann der Content nicht sofort verfügbar sein
- **Große Dateien**: Diff-Ansicht sollte große Dateien lazy laden
- **Session-Wechsel**: Beim Schließen des Projekts Session verwerfen (keine Persistenz in Slice 5)
- **Performance**: `changedFilePaths` Set für O(1) Lookup im FileTree
